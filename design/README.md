# Design

Work in progress. Nothing here is deployed; open the HTML files directly in a browser.

## `homepage/`

The new seven//acre homepage, which will replace `site/index.html`.

- `index.html`: current version (interactive three.js 7A in the hero, with a Chrome/Glass toggle).
- `violet.html`: colour studies (violet gradients on an off-white ground).
- `marks.html`: logo marks shown in containers.
- `versions/`: earlier rounds, kept for reference.

To ship it, move the finished page into `site/` and push to `main`.
