# Brand

seven//acre logo files. Brand colours: **#101010** (near-black) and **#EBEBEB** (light grey).

## Icon: `icon/`

The rounded 7A monogram in a square container. `dark` is a #101010 tile with a light 7A; `light` is a #EBEBEB tile with a dark 7A. Full size is 122×120, small is 61×60.

| File | Use |
|---|---|
| `7ad-icon-dark.svg` / `7ad-icon-light.svg` | Default icon, avatars, app icons |
| `7ad-icon-light-small.svg` | Small sizes (favicons, 32px and under) |
| `7ad-icon-dark-small-registered.svg` | Small size with the ® mark |

## Wordmark: `wordmark/`

`dark` is #101010 lettering for light backgrounds; `light` is #EBEBEB lettering for dark backgrounds. All three are 54 units tall.

The wordmark is responsive. It always runs the full width of its container and shortens as the screen narrows:

| Screen | Wordmark | Files |
|---|---|---|
| Desktop | SEVEN//ACRE | `7ad-wordmark-seven-{dark,light}.svg` |
| Tablet | SEVN//ACRE | `7ad-wordmark-sevn-{dark,light}.svg` |
| Mobile | SVN//ACRE | `7ad-wordmark-svn-{dark,light}.svg` |

## Other folders

- `source/`: the original Figma exports the files above were made from.
- `fonts/`: Montserrat (variable), used for the earlier wordmark. Open Font License.
- `archive/2026-10-08-marks/`: earlier mark explorations, superseded by `icon/` and `wordmark/`.

The live site at 7acredigital.com still uses the previous "Estate Italic" logo in `site/assets/` until the new homepage (`design/homepage/`) ships.
