# Brand

seven//acre logo files, exported from Figma.

## Colour

| | Hex |
|---|---|
| Near-black | `#101010` |
| Light grey | `#EBEBEB` |

## Type

**Inter Tight** for body text ([Google Fonts](https://fonts.google.com/specimen/Inter+Tight)). The wordmark is outlined artwork, so it needs no font.

## Icon: `icon/`

The rounded 7A monogram in a square container. `dark` is a #101010 tile with a light 7A; `light` is a #EBEBEB tile with a dark 7A.

| File | Size | Use |
|---|---|---|
| `7ad-icon-dark.svg` / `7ad-icon-light.svg` | 122×120 | Default icon, avatars, app icons |
| `7ad-icon-light-small.svg` | 61×60 | Small sizes (favicons, 32px and under) |
| `7ad-icon-dark-small-registered.svg` | 61×60 | Small size with the ® mark |

## Wordmark: `wordmark/`

`dark` is #101010 lettering for light backgrounds; `light` is #EBEBEB lettering for dark backgrounds.

The wordmark is responsive. It always runs the full width of its container and shortens as the screen narrows:

| Screen | Wordmark | Files |
|---|---|---|
| Desktop | SEVEN//ACRE | `7ad-wordmark-seven-{dark,light}.svg` |
| Tablet | SEVN//ACRE | `7ad-wordmark-sevn-{dark,light}.svg` |
| Mobile | SVN//ACRE | `7ad-wordmark-svn-{dark,light}.svg` |
